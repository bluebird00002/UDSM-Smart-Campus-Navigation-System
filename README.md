# UDSM Smart Campus Navigation — Prototype

Prototype built with Vite + React + Tailwind CSS + React-Leaflet.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes:
- No backend; data is mocked in `src/mockData.js`.
- Map uses OpenStreetMap tiles and `react-leaflet`.
